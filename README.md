# 🔐 Steganography Encoder

A full-stack web application that allows users to securely hide and extract secret messages inside images using steganography techniques.

Built using:

- ⚛️ React + Vite (Frontend)
- 🟢 Node.js + Express (Backend)
- 🖼️ Jimp for image processing
- 🔒 Crypto-JS for encryption

---

# 🚀 Features

- Hide secret messages inside images
- Extract hidden messages from encoded images
- Encrypt messages before embedding
- Upload and process images securely
- Fast and responsive UI
- Full-stack architecture
